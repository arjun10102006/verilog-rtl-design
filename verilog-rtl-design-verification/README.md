# Verilog RTL Design 

A collection of digital design modules implemented in **Verilog HDL** and functionally verified using **Xilinx Vivado XSim**.

This repository contains RTL implementations covering combinational logic, sequential logic, counters, finite state machines, frequency dividers, and shift registers. Each design is accompanied by a testbench for simulation and verification.

---

## Tools & Technologies

- **Verilog HDL**
- **Xilinx Vivado 2025.2**
- **XSim Simulator**
- RTL Design
- Behavioral Modeling
- Functional Verification
